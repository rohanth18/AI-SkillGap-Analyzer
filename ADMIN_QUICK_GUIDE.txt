  QUICK GUIDE: Change Admin Credentials
═══════════════════════════════════════════════════════════════

📌 IMPORTANT: Stop the backend server first (Ctrl+C in backend terminal)

═══════════════════════════════════════════════════════════════
METHOD 1: Change Existing Admin (RECOMMENDED)
═══════════════════════════════════════════════════════════════

Windows:
────────────────────────────────────────────────────────────────
cd "d:\Mca Main project just user module\Mca Main project just user module\project_v2\backend"
venv_new\Scripts\python.exe change_admin.py

Mac/Linux:
────────────────────────────────────────────────────────────────
cd project_v2/backend
source venv_new/bin/activate
python change_admin.py

The script will:
1. Show all users in database
2. Ask for current admin email
3. Ask for new email, password, and name
4. Update the credentials

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "User not found"
Solution: Run view_admin.py to see current admin email

Problem: Script errors
Solution: Make sure backend server is stopped first

Problem: "Email already exists"
Solution: Use change_admin.py instead of create_admin.py

SECURITY TIPS
═══════════════════════════════════════════════════════════════

✓ Use strong passwords (8+ characters)
✓ Don't share admin credentials
✓ Backup database before changes
✓ Delete scripts after use if they contain passwords
