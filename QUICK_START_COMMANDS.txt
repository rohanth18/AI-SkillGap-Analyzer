🪟 WINDOWS COMMANDS
═══════════════════════════════════════════════════════════════

--- ONE-TIME SETUP ---

1. Backend Setup:
   cd project_v2\backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python -m spacy download en_core_web_sm

2. Frontend Setup (NEW TERMINAL):
   cd project_v2\frontend
   npm install

--- RUNNING THE APP (EVERY TIME) ---

Terminal 1 - Backend:
   cd project_v2\backend
   venv\Scripts\activate
   python app.py

Terminal 2 - Frontend:
   cd project_v2\frontend
   npm run dev

Open Browser: http://localhost:5173

🍎 MAC/LINUX COMMANDS
═══════════════════════════════════════════════════════════════

--- ONE-TIME SETUP ---

1. Backend Setup:
   cd project_v2/backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python -m spacy download en_core_web_sm

2. Frontend Setup (NEW TERMINAL):
   cd project_v2/frontend
   npm install

--- RUNNING THE APP (EVERY TIME) ---

Terminal 1 - Backend:
   cd project_v2/backend
   source venv/bin/activate
   python app.py

Terminal 2 - Frontend:
   cd project_v2/frontend
   npm run dev

Open Browser: http://localhost:5173
